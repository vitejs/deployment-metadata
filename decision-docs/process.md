# Standards Process Rationale

The three-stage process is meant to enable faster iterations on the experiment phase while keeping the stability in the later phase. It is inspired by the process of [RFC 2026 Section 4.1](https://datatracker.ietf.org/doc/html/rfc2026#section-4.1), which focuses on the concept of "implementation-driven standard".

The proposal directory moves between stage directories because maturity is a property readers must see immediately. Permanent VDM numbers keep identity stable while root package exports keep consumer imports stable.
