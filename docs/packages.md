# Packages

## `@vitejs/deployment-metadata-types`

Re-exports every standardized metadata declaration from one package root. The contracts are tool-agnostic, and each export's JSDoc states its VDM number and maturity stage.

## `@vitejs/deployment-metadata-helper`

Provides Vite specific participant definition and discovery. It returns raw participants and never interprets, resolves, selects, or applies a metadata kind. Detailed examples live in the package README files.
