# Repository Directories

- `docs/` contains normative process and contributor-facing repository guides.
- `decision-docs/` records rationale; it does not override normative specs.
- `metadata/proposed/` contains Proposed Standards (PS).
- `metadata/draft/` contains Draft Standards (DS).
- `metadata/standard/` contains Finalized Standards (FS).
- `metadata/<stage>/VDMxxxx/spec.md` defines each contract's semantics.
- `metadata/<stage>/VDMxxxx/types.d.ts` contains its canonical TypeScript declarations.
- `packages/` contains publishable workspace packages.
- `tests/` checks repository-wide contracts and public types.
- `scripts/` contains repository verification scripts.
